# ECON-03 v0.10.0：距離による地域相場

## 実装と試遊方式

新しいregional_prices設定で距離による基準価格を導入しました。既存の数量別単価・需給更新・在庫・台帳・投機用貨物保有は維持し、価格計算の基準部分にだけ接続します。未指定/null/disabledの旧世界は従来通りです。例はexamples/regional-trial.json。

- mode=distance_bias_v1、status=provisional。
- metric=shortest_configured_routes_v1。固定設定に存在する無向航路のdistanceを合計した最短距離です。
- production.sourcesに登録された当該商品の産出地のうち最短距離を採用。産出地自身は距離0。輸入だけの惑星は産出地と見なしません。生産量による重み付けはしません。
- 閉鎖航路も地理的な距離計算には含めます。実際の航行可否は従来通り別判定です。動的な開通状態はこの暫定距離方式を変えません。
- goodsに全商品を一度ずつ指定し、goods_id、origin_price（産地基準Cr）、price_per_distance（距離1当たりCr）、unreachable_price（到達不能/産出地なしの代替基準Cr）を持たせます。
- 基準価格=origin_price+最短距離×price_per_distance。産出地なし/経路なしでは明示された代替価格を使用し、暗黙に距離0へ置き換えません。
- 各基準値・係数は整数。基準値は正、係数は0以上。上限超過等の不正値は設定段階で拒否。

試遊例は商品の既存base_priceをorigin_priceに複写し、距離係数20 Cr、代替価格はその2倍。コピーした数値は設定値であり、商品マスターを後から参照して自動連動させる式ではありません。すべて正式バランス未確定の試遊値です。

## 需給による逆転

距離は価格の基準であり、価格の大小関係を固定しません。実際の単価は既存のclamp(地域基準+step_price×(target_stock−評価在庫),min_price,max_price)で求め、数量ごとの限界単価を合計します。
過剰在庫の遠方で産地より安くなること、品薄の産地で近隣より高くなることを許容します。供給回復・需要消費・プレイヤーの売買に伴う在庫変化がそのまま反映されます。上下限は従来の市場設定を使用するため、距離差が小さい/制限値に達したケースでは価格が同じになる場合もあります。
取引確定時の最新状態で再計算し、見積りは価格予約ではありません。一括と分割、同時点の往復売買、資金/積荷/在庫制約は従来と同じ処理です。

## データとハッシュ

地域基準は固定ルールからCatalog読込み時に導出し、現在在庫や市場価格の保存列を上書きしません。新方式では保存済みmarkets.priceを価格基準に使わず、地域基準を使用します。旧方式ではその列を引き続き使用します。
有効設定のハッシュでは新方式が使わない初期market.priceを射影から除外し、regional_pricesの全有効パラメータと産出定義・航路距離を含めます。現在在庫/提示価格/開発進捗は含めません。商品/航路の集合順・JSONキー順や言語はハッシュに影響しません。
rules_version=phase3-regional-1、設定射影スキーマ5。DBスキーマは7のまま。旧カタログcanonicalと既存要求結果は維持します。新ルール版への更新で世界全体の設定ハッシュは旧版から変わります。
燃料商品も通常商品と同じ地域価格処理に参加しますが、航行費用との連動はありません。ワープ費はnavigation設定のCr支払い、貨物消費なしです。

## CLI

```sh
python3.12 -m starroute --db data/regional-trial.db --config examples/regional-trial.json --player captain
```

regionで現在地の各商品の基準価格・距離・適用理由を日英表示します。marketは在庫を反映した次の1個の買値、trade-quoteは数量分の合計です。regionは現在の売買価格を保証しません。係留中のみ表示し、開発上限・非公開資源値は応答に含めません。
新規世界の試遊設定として利用し、既存DBへ設定を自動上書きしません。旧世界のregionは未設定と表示します。

## 確認事項と範囲

1. 正式距離方式（直線/航路等）、閉鎖航路・開通による価格変化の扱い。
2. 複数産出地の集約（最寄り/生産能力による重み付け等）。
3. 距離係数、産地基準、上下限、到達不能/産出地なし時の式と数値。
4. 地域要因と将来イベントの重ね方、輸入/物流との関係。

今回の無向・固定設定航路・最寄り・線形係数方式はprovisionalとして分離し、正式仕様に固定していません。急騰/急落イベントはECON-04、開発倍率/新産出品はECON-05のままです。需給による逆転は実装・検証しますが、ランダムイベントを実装したとは扱いません。Inter-BBS通信/接続判定はPhase 5です。
