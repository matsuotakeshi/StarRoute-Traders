# ECON-01〜02 v0.9.0：惑星別産出・生産能力・供給

## 実装

商品マスターとは独立したproduction定義を追加しました。惑星×商品ごとに産出可否・基本生産能力・対応産業を保持します。非産出品も初期在庫、プレイヤーの売却、明示的な輸入で流通できます。産出定義にない商品を自動で生産する処理はありません。
既存の在庫制約・数量別価格・台帳・需要・更新時計を再利用します。新方式は明示的に選択し、従来のfixed/stock_curve_v1はそのままです。旧supply_per_tickを産出能力へ読み替えません。

## 試遊設定と式

examples/production-trial.jsonを新規DBへ使用します。

- economy.mode=planet_supply_v1。時間間隔/価格曲線/需要/在庫上限は従来の経済設定に置きます。
- このmodeのmarket行にはsupply_per_tickを置けません。二重供給を防ぐため拒否します。
- production.mode=per_planet_v1、status=provisional。
- sources: planet_id、goods_id、industry、units_per_tickを指定。産出地だけを列挙し、同じ惑星/商品を重複登録しません。
- industry: primary/secondary/tertiary/quaternaryのいずれか。固定の生産適性との対応であり、開発進捗の倍率ではありません。
- imports: planet_id、goods_id、units_per_tickを指定。省略時は空配列。生産定義と別の有限な供給です。
- 数量は正の整数。生産しない場合はsourcesから省略します。

周期はeconomy.tick_seconds。n期間経過時の在庫はclamp(旧在庫+n×(生産能力+輸入量−需要量),0,stock_limit)。生産と需要を同時相殺する試遊方式です。購入可能数量は現在在庫まで。売却で在庫が増え、上限を超える売却は拒否します。上限で失われた供給を貯蔵/後払いしません。
長時間分を期間ごとのループなしで計算し、端数時間を維持。再読込み・同時アクセス・再送で同じ期間を二重更新しません。失敗取引では時計/在庫/資金/台帳を同時にロールバックします。

試遊例: Auroraは星穀6/周期、Forgeは星穀2・合金4/周期、Havenは医療品3/周期。Havenの星穀は生産せず輸入2/周期。周期60秒、各市場の需要1/周期です。商品名/産出地/数値は正式設定ではありません。

importsは試遊用の外部供給枠です。自動物流/貨物輸送や、産出地の在庫からの自動引落しを実装したものではありません。暗黙の無制限な輸入はなく、定義がなければ0です。将来の実物流方式は別途確認します。
時間を進めなければ在庫枯渇後は購入できません。生産を続ける世界で長期の累積利益を禁止する仕様ではなく、有限時間内の供給量を有限に保ちます。

## データ分類・互換性

商品マスター、産出定義、初期市場値、実在庫、開発進捗を分離。productionと新economyパラメータは共有Game Rulesに含みます。sources/importsは惑星/商品ID順に正規化。説明用statusと表示言語は除外し、在庫・現在価格・進捗は動的状態としてハッシュ対象外です。
rules_version=phase3-production-1、設定射影スキーマ4。版更新によって旧版からハッシュは変わります。既存見積りcanonical・保存済み要求結果は変更していません。

DBスキーマは7のまま。新しい変動状態を追加せず、既存market/economy_clockを利用します。v0.8.0のDBは移行なしで読み込め、世界ID・台帳・資産・航路・開発進捗を維持します。古いスキーマの既存移行経路も維持。ファイル変更で既存DBへ産出設定を自動適用しません。
旧方式でproductionコマンドを実行すると未設定と表示し、従来の供給を生産と偽りません。新productionを旧経済modeへ混在させたり、新経済modeでproductionを省略した設定は拒否します。

## CLIと検証用デモ

```sh
python3.12 -m starroute --db data/production-trial.db --config examples/production-trial.json --player captain
```

```text
register Captain
production
market
buy grain 3
production
```

productionは現在地の生産量・対応産業・輸入量・購入可能在庫を日英表示します。係留中だけ使用可能。非公開の開発上限・資源特性値は応答へ含めません。
`scripts/production_demo.py`は独立した一時DBと手動時計を使い、60秒の生産/輸入/需要、再起動しても二重供給しないことをCLIで示します。実データの時計は変更しません。

## 今回の範囲と確認事項

ECON-01〜02を実装。地域距離価格はECON-03、急騰/急落などの統合はECON-04、開発進捗による生産能力増加/産出品解禁はECON-05のままです。産業は今回固定対応を定義するまでで、投資した瞬間に生産量は増えません。非公開上限は維持し、表示しません。Inter-BBS通信・接続判定はPhase 5です。
