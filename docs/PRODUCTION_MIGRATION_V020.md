## 発生した問題と対応

- `pkg install -n`では2パッケージの追加予定が表示されたが、実際の`pkg install`はリポジトリ内に対象がないとして失敗。その後、指定されていた旧STAGEのファイル不在も確認された。ファイルが消失した経緯は未確定であり、pkg仕様だけを原因と断定しない。
- 実ファイルのある`$STAGE/repo/All/`を確認して`pkg add`を実行し、導入成功。
- 旧0.18.0→0.19.0切替スクリプトの再実行は、旧パスの検査で停止。検査を削除して進めることはしていない。
- [移行手順](PKG_MIGRATION_V020.md)を実際に成功した方式へ修正した。
